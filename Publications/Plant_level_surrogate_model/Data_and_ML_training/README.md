## Code Structure
- `newDATA`: contains the training and testing datasets for light and water models, which are generated by FruitCropXL.
- `load_dataset.py`: Data loading script for the target dataset.  
- `ML_regression.py`: Model training and evaluation script for the target dataset. 
- `plot.py`: Visualization script for the experimental results.

## Dataset Structure
- The original dataset has been preprocessed into a light interception part (`merged_light_train.csv` and `merged_light_test.csv`) and a water flux part (`merged_water_train.csv` and `merged_water_test.csv`), that are further split into training and test sets. 
- Each set contains the input features and target variables as described above. 
- Specify the task `--task` (`'light'` or `'water'`)

## Train an ML Model (Adaboost Regressor and MLP Regressor)
- Specify the hyperparameters (e.g., `--task` and  `--seed`) in `run_train.sh`
```shell
  sh run_train.sh
```

## Test the Trained Model
- Specify the hyperparameters (e.g., `--task` and `--model_path`) in `run_test.sh`
```shell
  sh run_test.sh
```

## Note
This codebase is based on the new dataset which is generated by sampling the parameter space using the Latin hypercube sampling (for training) and structred grid search (for validation/test).
This dataset aims to provide a more comprehensive coverage of the parameter space, which can help to better evaluate the performance of surrogate models in predicting the target variables under different configurations.
